# SwiftType

A typing speed test application built with React, Tailwind CSS, and React Router. Practise typing, test your speed, and improve your accuracy.

## Live Demo

[View Live Site](https://swifttype-blond.vercel.app/)

## Screenshots

![SwiftType Home Page](./images/swifttype.png)

## Features

- Interactive typing test
- Typing speed and accuracy tracking
- Timed typing sessions
- Text passages for typing practice
- Responsive user interface

## Built With

- React
- JavaScript
- Tailwind CSS
- React Router
- Vite

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Jabezgreenan/SwiftType.git
   ```

2. Navigate to the project directory:

   ```bash
   cd SwiftType
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

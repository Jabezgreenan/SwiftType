# SwiftType

A site made to test your typing skills.

## Perview

![SwiftType Home Page](./images/swifttype.png)

## Features
- Listens for keystrokes and saves them in state
- Displays your total score while you typing in real-time
- You can restart the test with the restart button
- You can skip the test you are writing and do a new one

## Tech Stack
- React
- HTML
- Tailwind CSS
- JavaScript
- React Router
